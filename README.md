# Cerveau Quar-Parti — Mémoire Chrome Active

Ce dépôt privé sert de **cloud central d’indexation et de mémoire de travail** pour l’écosystème NickelRamQc94. Il relie les 41 dépôts GitHub du profil, y compris les forks, et fournit un endroit structuré pour consigner projets, décisions, notes et références.

## Ce que ce dépôt fait

- Centralise les liens des 41 dépôts connus, avec statut fork lorsqu’il a été fourni par l’inventaire GitHub.
- Sert de carnet évolutif pour ajouter des notes et relier les informations aux dépôts concernés.
- Sépare les faits observés, les informations rapportées et les éléments qui restent à vérifier.

## Ce qu’il ne fait pas automatiquement

- Il ne copie pas le contenu ni l’historique Git des 41 dépôts dans ce dépôt.
- Il ne synchronise pas automatiquement les changements faits dans les dépôts sources.
- Il ne constitue pas une mémoire persistante intégrée aux assistants ou aux conversations.

Pour maintenir le catalogue à jour, actualiser `CATALOGUE-41-DEPOTS.md` à partir de la page GitHub du profil. Garder ce dépôt privé si les notes ou liens qu’on y ajoute sont personnels.

## Structure

- [`CATALOGUE-41-DEPOTS.md`](CATALOGUE-41-DEPOTS.md) — inventaire des dépôts, incluant les forks.
- [`MEMOIRE-ACTIVE.md`](MEMOIRE-ACTIVE.md) — modèle de mémoire évolutive et de journal de décisions.
